Product thesis: Turn each direct report profile into a meeting-ready career coaching brief that helps managers run better growth conversations in under 2 minutes.
Problem statement
Managers want to support report growth, but they usually lack the time, confidence, and context to prepare for career conversations. Today, the product surfaces signals, notes, and themes, but managers still have to translate that information into a usable conversation plan themselves. That gap causes them to defer growth conversations or default to generic advice. We lose repeat value because insight consumption doesn’t convert into a concrete managerial action.
Why now
Retention is low after initial insight consumption. The clearest path to better repeat usage is to help managers complete a real job before a real meeting. Career conversations are frequent, stressful, and high value, especially around review cycles and org change. We already have enough existing signal to generate a credible first draft without introducing new workflow burden.
Target user and core job to be done
Target user: Frontline and mid-level managers with 3–12 direct reports, especially newer managers.
JTBD: “Before I meet with a report, help me quickly understand their likely growth needs and give me a concrete way to run a useful career conversation.”
Key insights and evidence
Managers come back for meeting-ready artifacts more than passive summaries.
The bottleneck is preparation structure, not intent.
Trust depends on visible grounding in notes, feedback, and prior themes.
A per-report artifact fits existing manager workflow better than a broad team-level tool.
Goals and non-goals
Goals
Increase repeat usage of report pages.
Reduce growth conversation prep time to under 2 minutes.
Increase manager confidence starting development conversations.
Make recommendations feel editable and evidence-based.

Non-goals
Full career ladder/framework in MVP.
Employee-facing sharing.
Formal performance review replacement.
Promotion or attrition prediction.
Hypotheses
If each report page includes a meeting-ready career brief, managers will return more often before 1:1s and review cycles.
If each recommendation is tied to explicit evidence, trust and usage will increase.
If the artifact is lightweight and editable, adoption will beat a rigid template.
Solution overview
Add a Career brief module to each direct report page with 5 sections:
Growth snapshot — likely aspirations, strengths, development area
Evidence highlights — 3–5 cited observations from notes/feedback/themes
Conversation plan — 3 suggested talking points, 2 open-ended questions
Suggested support — concrete actions the manager can offer
Prep note — editable manager note before the meeting
The brief is clearly labeled as a draft, includes inline evidence citations, and supports copy / edit / regenerate actions.
